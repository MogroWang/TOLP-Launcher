把游戏文件放到这个文件夹
========================

本启动器会自动加载此文件夹中的网页版游戏。

放置方法：
1. 用 GDevelop 将《光点之旅》导出为「网页版 / HTML5」；
2. 把导出得到的全部文件复制到本文件夹（确认本文件夹里有 index.html）；
3. 重新打开启动器或点击「启动游戏」即可。

数据文件夹说明：
启动器会在 exe 同目录创建 launcher-data/ 数据文件夹：
- versions/  存放游戏版本（每个版本一个子文件夹，版本管理页会自动识别）；
- saves/     存放游戏存档（浏览器数据），随启动器目录一起移动。

也可以不使用本文件夹：
在启动器「版本管理 → 自定义位置」或「快速启动 → 自定义启动」中
直接选择其他包含 index.html 的游戏目录。
